# Testes de Hardware

## Instruções

Nesta etapa, serão feitos os testes dos componentes na placa Raspberry Pi:

- Conectem partes fundamentais ao Raspberry Pi, de acordo com o projeto proposto (por exemplo, GPS, temperatura, envio de e-mail, câmera digital, reconhecimento facial etc.);
- Demonstrem que é possível utilizar cada uma das partes com o Raspberry Pi.
- Nesta entrega, é permitido utilizar linguagens interpretadas (Python, Octave etc.) e programas prontos.
